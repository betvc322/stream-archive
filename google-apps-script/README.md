# Google Apps Script — альтернативный источник для GitHub Pages

Этот способ использует RichTextValue API Google и не зависит от HTML-оформления публикации. Он понадобится, если формат публичной страницы изменится или вы предпочтёте прямое чтение ячеек. Исходную таблицу в этом случае публиковать целиком не требуется.

### Вставьте код

1. Откройте **исходную таблицу в режиме редактора**, затем **Расширения → Apps Script**. Ссылки на публичную страницу с `2PACX` недостаточно для открытия редактора скрипта.
2. Назовите проект «Архив стримов».
3. Удалите содержимое `Code.gs` / `Код.gs` в редакторе Google и вставьте весь код из [`google-apps-script/Code.gs`](Code.gs).
4. В начале кода заполните `SPREADSHEET_ID` и `SHEET_NAME`.

ID исходной таблицы — часть обычного адреса редактора между `/d/` и `/edit`. Это **не** число `gid` и **не** идентификатор публикации `2PACX-…`. Название листа — надпись на вкладке внизу таблицы, с точным совпадением пробелов.

Настройки `MOVIE_POSTER_COLUMN: 3` и `SERIES_POSTER_COLUMN: 4` означают C и D. Их можно изменить, если впоследствии поменять структуру именно для Apps Script; чтение публичной версии рассчитано на A:D.

5. В Apps Script откройте **Настройки проекта → Показывать файл манифеста appsscript.json в редакторе**.
6. Вставьте содержимое [`google-apps-script/appsscript.json`](appsscript.json) в появившийся файл манифеста.
7. Сохраните проект.

### Разрешения Google и проверка

1. Выберите функцию **testCatalog** в верхнем списке и нажмите **Выполнить**.
2. При первом запуске нажмите **Просмотреть разрешения**, выберите аккаунт с доступом к таблице и подтвердите разрешение на Google Таблицы.
3. Для собственного непроверенного скрипта Google может показать предупреждение. Откройте **Дополнительные настройки → Перейти к вашему проекту…** и подтвердите доступ.
4. В журнале выполнения появятся JSON и число записей со ссылками.

Метод `SpreadsheetApp.openById()` требует scope `spreadsheets`, а не `spreadsheets.readonly`. Поэтому Google запрашивает широкое разрешение на просмотр и изменение доступных аккаунту таблиц (в формулировке также могут быть создание и удаление). **Предоставленный код только читает настроенную таблицу и не содержит операций изменения или удаления.** Отдельные разрешения Google Drive, доступ к почте и вход в Boosty не требуются.

Проверьте, что у записи со ссылкой `url` содержит настоящий адрес Boosty, у сериала сезон отделён от названия, а `posterUrl` совпадает с C или D. Скрипт проверяет целую ячейку через `getLinkUrl()`, затем фрагменты через `getRuns()` и `getLinkUrl()`. Из нескольких ссылок выбирается первая подходящая ссылка Boosty.

Есть запасная обработка `HYPERLINK()` / `ГИПЕРССЫЛКА()` со строковым URL и прямой ссылкой на ячейку того же листа. Запятая и точка с запятой поддерживаются. Сложные формулы вроде `CONCAT` могут не предоставить URL через RichText; самое простое решение — назначить прямую ссылку через Ctrl+K / ⌘K.

### Опубликуйте Web App

1. Нажмите **Развернуть → Новое развертывание**.
2. В выборе типа через шестерёнку укажите **Веб-приложение / Web app**.
3. **Запуск от имени — Меня / Me**.
4. **У кого есть доступ — Все / Anyone**, включая пользователей без входа в Google.
5. Нажмите «Развернуть» и подтвердите разрешения, если Google попросит.
6. Скопируйте **URL веб-приложения с окончанием `/exec`**. Не используйте `/dev`, адрес редактора или ID развертывания.
7. Откройте `/exec` в приватном окне без входа в Google: должен появиться JSON `{ "items": [...] }`.

В `catalog.config.json` укажите этот URL в поле `appsScriptUrl`. Поле `publishedSheetUrl` можно оставить заполненным. **Если заполнены оба адреса, приоритет у Apps Script.** Ошибка настроенного источника не подменяется другим источником или демонстрационными данными.

Если аккаунт Google Workspace не разрешает доступ «Все», потребуется разрешённый администратором способ либо личный аккаунт с доступом к таблице.

При изменении ячеек повторное развертывание не нужно. После изменения кода Apps Script: **Развернуть → Управление развертываниями → карандаш → Версия: Новая версия → Развернуть**. URL существующего развертывания сохранится.
